# Portfólio

Este repositório contém um projeto de portfólio pessoal que desenvolvi. O objetivo é apresentar informações profissionais, habilidades, projetos e formas de contato de maneira moderna e responsiva.

## Estrutura do Projeto
- `index.html`: Página principal do portfólio.
- `style.css`: Estilos personalizados para o layout e responsividade.
- `script.js`: Funcionalidades interativas (menu mobile, accordion, carrossel, validação de formulário).
- `img/`: Imagens utilizadas no site (perfil, ícones, projetos, etc).

## Funcionalidades
- Menu responsivo para navegação em dispositivos móveis.
- Accordion para exibir informações de forma organizada.
- Carrossel de imagens para mostrar projetos.
- Formulário de contato com validação.

## Como usar
1. Clone o repositório:
   ```bash
   git clone https://github.com/JFernandosp/Portifolio.git
   ```
2. Abra o arquivo `index.html` em seu navegador.
